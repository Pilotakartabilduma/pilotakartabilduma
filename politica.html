Política de Privacidad

Esku Pilota Card Game es un videojuego gratuito desarrollado por Studio Baraxka.

Esta aplicación no recopila, almacena ni comparte datos personales de los usuarios.

Información recopilada

La aplicación no solicita registro de usuario ni recopila información personal identificable.

Publicidad

La aplicación no muestra publicidad.

Compras integradas

La aplicación no contiene compras dentro de la aplicación.

Permisos del dispositivo

La aplicación no accede a la cámara, micrófono, ubicación, contactos ni otros datos personales del dispositivo.

Menores de edad

La aplicación está diseñada para todos los públicos.
